# Recipe Finder App with AI Chatbot

A modern and interactive Recipe Finder web application built using **React.js**. This application allows users to search for delicious recipes and get cooking suggestions through an integrated AI chatbot.

---

## Features

- Search recipes by name or ingredients.
- Browse a variety of recipes.
- View detailed recipe information.
- AI chatbot for cooking assistance and recipe recommendations.
- Responsive design for mobile and desktop devices.
- Fast and user-friendly interface.

---

## Tech Stack

### Frontend
- React.js
- Javascript
- HTML5
- CSS3

### APIS
- Recipe API
- AI Chatbot API
